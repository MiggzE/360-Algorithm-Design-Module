How to run

The algorithms are just python scripts so you can just run them with ./  in a linux terminal or just run it how you would normally would 
run a python file in your IDE. It does not take in any files and will just ask for a string input to compute. In the LCubS_Improved.py file there 
is a function commented out to call the stress test function so if you want to see that you can just uncomment it.
