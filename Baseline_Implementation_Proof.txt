Longest Cubic Subsequence proof

To properly prove our solution we need to check for progress and termination

Termination:
Our main iterative step is from the recusive function inside LCubS, findLCubS.

Our base case for the recursive function is if i equals to the length of our main string.
This prevents the recusive function from going out of the bounds of the main string.
In every recusive function call in findLCubS we iterate i by one, which means that i never goes
down or stays where its at. That means that i will reach the length of the main string at some point
When we initially start the recursive calls we call findLCubS with an i of 0 so even if the main string
is an empty string it will terminate. The length of the main string can also never be a negative number 
since a string is needed to be passed through for the LCubS function. 

Progress:

In order to prove progress we need to reiterate what we are trying to solve
Given a string S we need to find the largest sequence X that repeats from within that string 3 times with the ability 
to keep or remove letters. However, their relative position should stay the same. 

We can obtain subsequences of the string by creating a recursive function to add or skip letters from our main 
string to a temp string which would apply the same logic to those 2 cases.

        addCurrLetter = findLCubS(i + 1, curr + s[i])
        skipCurrLetter = findLCubS(i + 1, curr)

Once we create a new subsequence we need to verify it. This is what our isCubic(string)
function does. 

First it checks if the string is a multiple of 3 using the modulo sign since it can't be a cubic subsequence
if each third of the subsequence is not the same length. If that passes then it cuts the string into 3 seperate
slices and compares them to each other. If all of those slices equal the same string then
its a valid subsequence otherwise it isn't.

Inductive Hypothesis:

Basecase = i == len(s)

As previously stated, since i starts at 0 the smallest that len(s) can be is 0 
Thus the basecase for i = 0 is valid

k = i
Assume all cases from 0 to k are valid states

Iteration k + 1

In our current state we can create every possible state after that by recursively calling our 2 possible 
states. Adding a letter to the subsequence and skipping a letter.

By doing this in each state we explore every possible state until we have exhausted every single letter 
in our main string.

Once we reach our base case

if our current subsequence is valid
as defined by len(curr) % 3 != 0 and curr[:1/3] == curr[1/3:2/3] == curr[2/3:]
then it returns the current subsequence 
if it isn't then it returns an empty string.

When the recursive calls propagate up it compares the states that have added a letter to the
current subsequence and the ones that have skipped it and determines which subsequence is the
largest.
